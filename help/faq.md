## What is Stratum?

Stratum is a server runtime for Vintage Story multiplayer. It runs in place of the stock dedicated server, and it adds performance work, server hardening, staff and player commands, chat and presentation options, and reports for owners.

## Do players need to install anything?

No. Players connect with a normal Vintage Story client on the same game version as the server.

## Is Stratum a fork of Vintage Story?

Stratum builds on the Vintage Story server, and it patches parts of that server to add its features. It is not a separate game.

## Does Stratum send data anywhere?

Yes, by default. Stratum sends anonymous statistics about your server, and it checks GitHub for new releases. Both can be turned off. [Privacy and outbound requests](/docs/configuration/privacy-and-outbound-requests) lists every field and how to turn each one off.

## Is Stratum compatible with Synergy or Tungsten?

No. Stratum already includes the optimizations those mods provide, so running them together conflicts. See [Compatibility overview](/docs/compatibility/overview).

## Do I have to update when Vintage Story updates?

Yes. Each Stratum release is built for one Vintage Story version. When the game updates, run the Stratum release for the new version. See [Updating](/docs/getting-started/updating).

## Where do I report a bug?

Open an issue on the [Stratum GitHub repository](https://github.com/StratumServer/Stratum/issues). The index page also lists the Discord, which is the fastest way to reach the team.
